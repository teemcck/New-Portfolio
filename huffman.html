What is Huffman coding?

According to Huffman's original paper in (date), it is a process we may use to abbreviate binary sequences (huffman codes) to be expanded again later. The information required to reinterpret this abbreviated data is included in the "codebook," a small header excerpt bundled with compressed data. Huffman's original paper included a sample algorithm which became the understanding for how the process was performed. However, this process has heavily evolved over time (as things tend to do over the course 70 years). This abstracted introduction to the subject was not without purpose. Huffman coding, in modern use, pertains to no particular implementation. In fact, modern implementations seem like frankensteined variants of Huffman's original proposed process.

How is this implemented?

In the interest of making this project modernized, yet still true to Huffman's original implementation, I will implement a "canonical" Huffman coding algorithm leverging Huffman's original greedy tree merging solution.
